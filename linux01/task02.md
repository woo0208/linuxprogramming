# 가상머신 및 Linux CLI 조사

## 1. 가상머신이란 무엇인가?

가상머신(VM, Virtual Machine)이란 **하나의 실제 컴퓨터 안에서 다른 컴퓨터처럼 동작하도록 만들어진 가상의 컴퓨터 환경**을 의미한다.

가상머신은 물리적인 컴퓨터의 CPU, 메모리, 저장장치 등의 자원을 소프트웨어적으로 나누어 사용할 수 있도록 한다. 따라서 하나의 컴퓨터에서 Windows를 실행하면서 동시에 Linux와 같은 다른 운영체제를 실행할 수 있다.

가상머신을 관리하는 소프트웨어를 **하이퍼바이저(Hypervisor)**라고 하며, 대표적인 프로그램으로 VMware, VirtualBox, Hyper-V 등이 있다.

예를 들어 Windows PC에서 VirtualBox를 이용하여 Ubuntu Linux를 설치하면, Windows를 종료하지 않고도 Ubuntu를 가상머신으로 실행할 수 있다.

---

## 2. 가상머신을 사용하는 이유를 설명하라.

가상머신을 사용하는 대표적인 이유는 다음과 같다.

- **여러 운영체제 사용**
  - 하나의 컴퓨터에서 Windows, Linux 등의 여러 운영체제를 사용할 수 있다.

- **개발 및 테스트 환경 구축**
  - 프로그램이나 서버를 실제 컴퓨터에 직접 설치하지 않고 독립적인 가상환경에서 테스트할 수 있다.

- **시스템 격리**
  - 가상머신에서 발생한 오류나 문제가 실제 운영체제에 미치는 영향을 줄일 수 있다.

- **서버 자원의 효율적인 사용**
  - 하나의 물리 서버에서 여러 개의 가상 서버를 실행하여 하드웨어 자원을 효율적으로 사용할 수 있다.

- **실험 및 학습**
  - 운영체제나 Linux 명령어 등을 실제 컴퓨터의 시스템에 큰 영향을 주지 않고 연습할 수 있다.

따라서 가상머신은 **하나의 물리적인 컴퓨터에서 여러 독립적인 환경을 만들고 관리할 수 있다는 점**에서 유용하다.

---

## 3. WSL2가 다른 가상머신 소프트웨어와 비교하여 장점이 무엇인가?

**WSL2(Windows Subsystem for Linux 2)**는 Windows에서 Linux 환경을 사용할 수 있도록 Microsoft에서 제공하는 기능이다.

WSL2는 실제 Linux 커널을 기반으로 동작하며 Windows와 Linux 환경을 함께 사용할 수 있도록 해준다.

일반적인 가상머신 소프트웨어와 비교했을 때 WSL2의 장점은 다음과 같다.

- **설치와 실행이 간편하다.**
  - 일반적인 가상머신보다 복잡한 가상 하드웨어 설정이 필요하지 않다.

- **Windows와 Linux의 연동이 편리하다.**
  - Windows 파일 시스템에 접근하거나 Windows 프로그램과 Linux 명령어를 함께 사용할 수 있다.

- **개발 환경 구축에 유리하다.**
  - Git, Python, GCC 등의 Linux 기반 개발 도구를 Windows에서 편리하게 사용할 수 있다.

- **관리하기 편리하다.**
  - 별도의 가상머신 창에서 전체 운영체제를 관리하는 것보다 간편하게 Linux 환경을 사용할 수 있다.

- **Linux 커널을 사용한다.**
  - WSL1에 비해 Linux 시스템과의 호환성이 높아졌다.

### WSL2와 일반적인 가상머신의 비교

| 구분 | WSL2 | 일반적인 가상머신 |
|---|---|---|
| 주요 목적 | Windows에서 Linux 환경 사용 | 독립적인 가상 컴퓨터 운영 |
| 설치 및 설정 | 비교적 간단함 | 상대적으로 복잡함 |
| Windows 연동 | 매우 편리함 | 별도의 설정이 필요한 경우가 있음 |
| 개발 환경 | Linux 개발 환경 구축에 적합 | 다양한 운영체제 테스트에 적합 |
| 독립성 | Windows와 밀접하게 연동 | 독립적인 운영체제 환경 구성 가능 |

따라서 **Windows에서 Linux 개발 환경을 편리하게 사용하려는 경우 WSL2가 적합**하며, 여러 운영체제를 완전히 독립된 환경에서 운영하거나 운영체제 자체를 실험하려는 경우 VMware나 VirtualBox 같은 일반적인 가상머신이 더 적합하다.

## 4. GUI, CLI의 장단점을 비교 설명하시오.

**GUI(Graphical User Interface)**는 아이콘, 창, 메뉴, 버튼 등의 그래픽 요소를 마우스와 키보드로 조작하는 인터페이스이다.

**CLI(Command Line Interface)**는 사용자가 명령어를 직접 입력하여 컴퓨터를 조작하는 문자 기반 인터페이스이다.

### GUI와 CLI 비교

| 구분 | GUI | CLI |
|---|---|---|
| 조작 방법 | 마우스와 키보드 | 명령어 직접 입력 |
| 사용 편의성 | 직관적이고 사용하기 쉬움 | 명령어 학습이 필요함 |
| 시스템 자원 | 상대적으로 많이 사용 | 상대적으로 적게 사용 |
| 자동화 | 상대적으로 불편함 | 스크립트를 이용하여 자동화하기 쉬움 |
| 반복 작업 | 번거로울 수 있음 | 빠르게 처리 가능 |
| 원격 관리 | 상대적으로 불편함 | 원격 서버 관리에 유리 |

### GUI의 장점

- 사용하기 쉽고 직관적이다.
- 아이콘과 메뉴를 통해 기능을 쉽게 확인할 수 있다.
- 명령어를 몰라도 사용할 수 있다.
- 이미지, 영상 등 시각적인 콘텐츠를 다루기 편리하다.

### GUI의 단점

- 그래픽 환경을 실행하기 위한 시스템 자원이 필요하다.
- 반복적인 작업을 자동화하기 어려운 경우가 있다.
- 세부적인 시스템 관리에는 CLI보다 불편할 수 있다.

### CLI의 장점

- 시스템 자원을 적게 사용한다.
- 명령어를 빠르게 입력하여 작업할 수 있다.
- 반복 작업을 스크립트로 자동화하기 쉽다.
- 원격 서버 관리에 적합하다.
- 시스템을 세부적으로 제어할 수 있다.

### CLI의 단점

- 명령어를 학습해야 한다.
- 명령어를 잘못 입력하면 오류가 발생할 수 있다.
- 초보자가 사용하기에는 GUI보다 어렵다.

---

## 5. CLI 방식의 인터페이스가 GUI 방식보다 처리속도가 빠른 이유를 설명하라.

CLI 방식이 GUI 방식보다 처리속도가 빠른 경우가 많은 이유는 **그래픽을 표시하고 처리하는 데 필요한 추가적인 작업이 적기 때문**이다.

GUI에서는 명령을 수행하기 위해 창, 아이콘, 메뉴, 버튼 등의 그래픽 요소를 화면에 표시하고 관리해야 한다. 이러한 그래픽 요소를 처리하기 위해 CPU, 메모리, GPU 등의 시스템 자원이 사용된다.

반면 CLI에서는 사용자가 텍스트 형태의 명령어를 입력하면 운영체제가 해당 명령을 실행하고 결과를 텍스트 형태로 출력한다.

예를 들어 현재 디렉터리의 파일 목록을 확인할 때 CLI에서는 다음과 같이 간단하게 입력할 수 있다.

```bash
ls
```

따라서 CLI는 GUI에 필요한 그래픽 처리와 화면 구성 작업이 상대적으로 적어 **시스템 자원 사용량과 인터페이스 오버헤드를 줄일 수 있다.**

다만 CLI가 모든 작업에서 GUI보다 항상 빠른 것은 아니다. 작업의 종류와 사용자의 숙련도에 따라 실제 작업 시간은 달라질 수 있다.

---

## 6. Linux에서는 왜 CLI 방식을 주로 사용하는가?

Linux에서 CLI가 많이 사용되는 가장 큰 이유는 **서버 운영과 시스템 관리에 CLI가 효율적이기 때문**이다.

Linux 서버는 GUI를 설치하지 않고 CLI 환경으로 운영되는 경우가 많다. GUI를 사용하지 않으면 그래픽 환경을 실행하는 데 필요한 CPU와 메모리 등의 자원을 절약할 수 있다.

또한 서버 관리자는 터미널을 통해 시스템을 빠르고 세밀하게 관리할 수 있다.

Linux에서 CLI를 사용하는 주요 이유는 다음과 같다.

- **서버 자원을 절약할 수 있다.**
- **원격 서버 관리가 편리하다.**
- **명령어를 이용해 시스템을 세밀하게 제어할 수 있다.**
- **Shell Script를 이용한 작업 자동화가 가능하다.**
- **반복적인 작업을 빠르게 처리할 수 있다.**
- **GUI가 없는 서버 환경에서도 사용할 수 있다.**

따라서 Linux에서는 특히 **서버 관리, 시스템 관리, 개발 등의 분야에서 CLI가 중요하게 사용된다.**

## 7. Linux 명령어란 무엇이고 중요 5개 명령어를 조사하라. 실행결과를 첨부하라.

### Linux 명령어란?

Linux 명령어란 **Linux 운영체제에서 터미널(CLI)을 통해 특정 작업을 수행하기 위해 입력하는 명령**을 말한다.

Linux 명령어를 사용하면 파일과 디렉터리를 관리하고, 프로그램을 실행하며, 시스템 정보를 확인하고 프로세스를 관리할 수 있다.

대표적인 Linux 명령어 5개를 다음과 같이 조사하였다.

### ① `pwd` - 현재 위치 확인

`pwd`는 **Print Working Directory**의 약자로, 현재 사용자가 위치한 디렉터리의 경로를 출력한다.

#### 사용법

```bash
pwd
```
