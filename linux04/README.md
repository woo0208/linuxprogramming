# 실습과제 1

## 디렉터리 및 경로 관련 용어

| 용어 | 설명 | 예시 |
|---|---|---|
| **디렉터리(Directory)** | 파일을 효율적으로 관리하기 위한 폴더이다. 파일이나 다른 디렉터리를 저장할 수 있다. | - |
| **서브 디렉터리(Sub Directory)** | 다른 디렉터리 안에 포함된 하위 디렉터리이다. | - |
| **작업 디렉터리(Working Directory)** | 현재 사용자가 작업하고 있는 디렉터리이다. 터미널에서 명령어를 실행할 때 기본이 되는 현재 위치이다. | - |
| **홈 디렉터리(Home Directory)** | 각 사용자에게 할당된 개인 디렉터리이다. 사용자의 파일이나 설정 등이 저장된다. | - |
| **`~`** | 현재 사용자의 홈 디렉터리를 나타내는 기호이다. | `~/data` |
| **`.`** | 현재 디렉터리를 나타내는 기호이다. | `./file.txt` |
| **`..`** | 현재 디렉터리의 상위 디렉터리(부모 디렉터리)를 나타내는 기호이다. | `../data` |
| **`/`** | 리눅스에서 가장 최상위에 있는 **루트 디렉터리**를 나타낸다. 또한 경로에서 디렉터리를 구분하는 구분자로 사용된다. | `/home/user` |
| **상대경로(Relative Path)** | 현재 작업 디렉터리를 기준으로 파일이나 디렉터리의 위치를 나타내는 경로이다. | `../data/file.txt` |
| **절대경로(Absolute Path)** | 루트 디렉터리(`/`)부터 시작하여 파일이나 디렉터리의 위치를 나타내는 완전한 경로이다. | `/home/user/data/file.txt` |



# 실습과제 2

| 번호 | 문제 | 명령어 | 경로 유형 |
|---|---|---|---|
| ① | 현재 작업 디렉터리 → 루트 디렉터리 | `cd /` | 절대경로 |
| ② | 현재 작업 디렉터리 → 루트 디렉터리 | `cd ../..` | 상대경로 |
| ③ | `/usr/lib/gcc/x86_64-linux-gnu`로 이동 | `cd /usr/lib/gcc/x86_64-linux-gnu` | 절대경로 |
| ④ | `/usr/lib/gcc/x86_64-linux-gnu`로 이동 | `cd usr/lib/gcc/x86_64-linux-gnu` | 상대경로 |
