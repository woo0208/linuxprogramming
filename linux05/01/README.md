# 실습과제3

### cat, more, less 명령어의 차이

- `cat`: 파일의 내용을 한 번에 전부 출력한다.
- `more`: 파일의 내용을 한 화면씩 순차적으로 출력한다.
- `less`: 파일의 내용을 화면 단위로 출력하며 위·아래로 자유롭게 이동할 수 있다.

예시:
cat file.txt
more file.txt
less file.txt
