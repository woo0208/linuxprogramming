## Bash 셸 주요 단축키

| 기능 | 단축키 | 설명 |
|---|---|---|
| 문자 단위 커서 이동 - 앞 | `←` 또는 `Ctrl + B` | 커서를 한 문자 왼쪽(앞)으로 이동 |
| 문자 단위 커서 이동 - 뒤 | `→` 또는 `Ctrl + F` | 커서를 한 문자 오른쪽(뒤)으로 이동 |
| 커서를 맨 앞으로 이동 | `Ctrl + A` | 현재 명령어의 맨 앞(시작)으로 이동 |
| 커서를 맨 뒤로 이동 | `Ctrl + E` | 현재 명령어의 맨 뒤(끝)으로 이동 |
| 단어 단위 커서 이동 - 앞 | `Alt + B` | 커서를 이전 단어의 시작 위치로 이동 |
| 단어 단위 커서 이동 - 뒤 | `Alt + F` | 커서를 다음 단어의 끝 위치로 이동 |
| 현재 위치 문자 삭제 | `Ctrl + D` | 커서가 위치한 문자를 삭제 |
| 뒤에 있는 문자 삭제 | `Backspace` | 커서 바로 앞의 문자를 삭제 |
| 뒤에 있는 단어 삭제 | `Ctrl + W` | 커서 앞쪽의 단어를 삭제 |
| 자르기 | `Ctrl + K` | 커서 위치부터 줄의 끝까지 잘라내기 |
| 붙여넣기 | `Ctrl + Y` | 잘라낸 내용을 현재 위치에 붙여넣기 |
| 화면 잠금 | `Ctrl + S` | 터미널 화면 출력 일시 정지 |
| 화면 잠금 해제 | `Ctrl + Q` | 일시 정지된 터미널 출력 재개 |
| 실행 종료 | `Ctrl + C` | 현재 실행 중인 명령을 강제로 종료 |
| 화면 삭제 | `Ctrl + L` | 터미널 화면을 깨끗하게 지움 |

### ⭐ 자주 사용하는 단축키

- `Ctrl + A` → 명령어 맨 앞으로 이동
- `Ctrl + E` → 명령어 맨 뒤로 이동
- `Ctrl + B` → 한 문자 뒤로 이동
- `Ctrl + F` → 한 문자 앞으로 이동
- `Alt + B` → 한 단어 뒤로 이동
- `Alt + F` → 한 단어 앞으로 이동
- `Ctrl + C` → 실행 중인 명령 종료
- `Ctrl + L` → 화면 지우기
- `Ctrl + D` → 현재 위치의 문자 삭제
- `Ctrl + W` → 이전 단어 삭제
- `Ctrl + K` → 현재 위치부터 줄 끝까지 삭제(잘라내기)
- `Ctrl + Y` → 잘라낸 내용 붙여넣기
