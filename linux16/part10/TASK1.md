## 템플릿 함수 핵심 정리

### 1. 템플릿 함수의 2가지 매개변수는?
- 템플릿 매개변수(Template Parameter)
- 함수 매개변수(Function Parameter)

### 2. 템플릿 매개변수의 용도는?
- 함수에서 사용할 자료형을 일반화하기 위한 매개변수이다.
- 호출할 때 전달되는 인수의 자료형에 따라 실제 자료형이 결정된다.
- 예: `template <class T>`에서 `T`가 템플릿 매개변수이다.

### 3. 함수 매개변수의 용도는?
- 함수가 실행될 때 필요한 실제 데이터를 전달받기 위한 매개변수이다.
- 일반 함수의 매개변수와 같은 역할을 한다.
- 예: `T bigger(T a, T b)`에서 `a`, `b`가 함수 매개변수이다.

### 4. 템플릿 함수의 정의는 호출과 같은 소스코드에 존재해야 하는 이유는?
- 템플릿 함수는 실제 자료형이 결정되어야 컴파일러가 함수를 생성할 수 있다.
- 컴파일러가 템플릿을 인스턴스화하려면 함수의 정의를 확인할 수 있어야 한다.
- 따라서 템플릿 함수의 정의를 호출하는 코드에서 확인할 수 있어야 한다.

### 5. 일반 함수와 템플릿 함수의 차이

| 구분 | 일반 함수 | 템플릿 함수 |
|---|---|---|
| 선언 | 헤더 파일(.h) | 헤더 파일(.h) |
| 정의 | 소스 파일(.cpp) | 일반적으로 헤더 파일(.h) |
| 이유 | 컴파일과 링크를 통해 연결 | 템플릿 인스턴스화에 정의가 필요 |

**참고:** 일반 함수는 선언을 헤더 파일에, 정의를 소스 파일에 분리할 수 있다. 하지만 템플릿 함수는 헤더 파일에 정의까지 작성하는 것이 일반적이다. 호출하는 소스 파일에서 해당 헤더 파일을 `#include`하면 템플릿 함수의 선언과 정의를 모두 확인할 수 있기 때문이다.
