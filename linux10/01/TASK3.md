# #if ~ #elif ~ #endif 전처리 지시자

## 1. #if ~ #elif ~ #endif 지시자를 사용하는 이유

C언어에서 `#if`, `#elif`, `#endif`는 조건부 컴파일을 수행하기 위한 전처리 지시자이다.

조건부 컴파일이란 프로그램을 컴파일하기 전에 특정 조건을 검사하고, 조건에 맞는 소스코드만 선택하여 컴파일하는 기능이다.

### 1.1 각 지시자의 역할

1. `#if`
   - 조건부 컴파일의 시작을 나타낸다.
   - 지정한 조건이 참이면 해당 코드가 컴파일 대상에 포함된다.
   - 조건이 거짓이면 해당 코드를 제외하고 다음 조건을 검사한다.

2. `#elif`
   - `else if`와 비슷한 역할을 한다.
   - 앞의 조건이 거짓일 때 새로운 조건을 검사한다.
   - 여러 조건을 순서대로 검사할 때 사용한다.

3. `#else`
   - 앞의 모든 조건이 거짓일 때 실행할 코드를 지정한다.
   - 생략할 수 있다.

4. `#endif`
   - 조건부 컴파일 영역의 끝을 나타낸다.
   - `#if`로 시작한 조건부 컴파일을 종료한다.

### 1.2 사용하는 이유

① 컴파일 환경에 따라 서로 다른 코드를 사용할 수 있다.

② 디버그 모드와 일반 실행 모드를 구분할 수 있다.

③ 특정 하드웨어나 운영체제에 필요한 코드만 컴파일할 수 있다.

④ 불필요한 코드를 컴파일 대상에서 제외할 수 있다.

⑤ 하나의 소스코드로 여러 설정의 프로그램을 관리할 수 있다.

일반적인 `if ~ else if ~ else` 문은 프로그램 실행 중에 조건을 검사하지만, `#if ~ #elif ~ #endif`는 컴파일 이전의 전처리 단계에서 조건을 검사한다는 차이가 있다.

## 2. #if ~ #elif ~ #endif 사용 예제

### 2.1 참고 자료

참고 사이트: cppreference - C언어 조건부 컴파일

https://en.cppreference.com/w/c/preprocessor/conditional.html

위 사이트에서 설명하는 조건부 컴파일 문법을 참고하여 프로그램의 실행 모드를 선택하는 예제를 작성하였다.

### 2.2 예제 소스코드

```c
#include <stdio.h>

#define MODE 2

int main(void)
{
#if MODE == 1
    printf("Mode 1: Debug mode\n");

#elif MODE == 2
    printf("Mode 2: Normal mode\n");

#elif MODE == 3
    printf("Mode 3: Power saving mode\n");

#else
    printf("Unknown mode\n");

#endif

    return 0;
}
```

### 2.3 실행 결과

컴파일 명령어:

```bash
gcc -std=c11 -Wall -Wextra conditional_example.c -o conditional_example
```

실행 결과:

```text
Mode 2: Normal mode
```

현재 `MODE`가 2로 정의되어 있으므로 `#elif MODE == 2` 조건에 해당하는 코드가 컴파일된다.

따라서 `Mode 2: Normal mode`라는 문자열이 출력된다.

## 3. 소스코드 상세 설명

### 3.1 헤더파일 포함

```c
#include <stdio.h>
```

- 표준 입출력 헤더파일을 포함한다.
- 화면에 문자열을 출력하는 `printf()` 함수를 사용하기 위해 필요하다.

### 3.2 매크로 상수 정의

```c
#define MODE 2
```

- `#define`은 매크로를 정의하는 전처리 지시자이다.
- `MODE`라는 매크로를 숫자 2로 정의한다.
- 이후 전처리 과정에서 `MODE`는 2로 치환된다.
- `MODE` 값을 변경하면 컴파일되는 코드가 달라진다.

### 3.3 첫 번째 조건 검사

```c
#if MODE == 1
    printf("Mode 1: Debug mode\n");
```

- `#if`는 첫 번째 조건을 검사한다.
- `MODE`가 1인지 비교한다.
- 현재 `MODE`는 2이므로 조건이 거짓이다.
- 따라서 해당 `printf()` 문은 컴파일 대상에서 제외된다.

### 3.4 두 번째 조건 검사

```c
#elif MODE == 2
    printf("Mode 2: Normal mode\n");
```

- 첫 번째 조건이 거짓이므로 두 번째 조건을 검사한다.
- `MODE`의 값이 2인지 비교한다.
- 현재 `MODE`는 2이므로 조건이 참이다.
- 따라서 해당 `printf()` 문이 컴파일 대상에 포함된다.
- 이후의 `#elif`와 `#else` 영역은 선택되지 않는다.

### 3.5 세 번째 조건

```c
#elif MODE == 3
    printf("Mode 3: Power saving mode\n");
```

- 앞의 조건들이 모두 거짓일 경우 검사하는 조건이다.
- `MODE`가 3이면 절전 모드라는 문자열을 출력하도록 설정한다.
- 현재는 앞의 `MODE == 2` 조건이 참이므로 이 영역은 컴파일 대상에서 제외된다.

### 3.6 그 외의 조건

```c
#else
    printf("Unknown mode\n");
```

- 앞의 조건이 모두 거짓일 때 선택되는 영역이다.
- `MODE`가 1, 2, 3 중 어느 값도 아니라면 해당 문자열을 출력하도록 설정한다.
- 예를 들어 `MODE`를 5로 변경하면 이 영역이 컴파일된다.

### 3.7 조건부 컴파일 종료

```c
#endif
```

- `#if`로 시작한 조건부 컴파일 영역을 종료한다.
- 전처리기는 해당 범위에서 선택된 코드만 컴파일 단계로 전달한다.

### 3.8 프로그램 종료

```c
return 0;
```

- `main()` 함수의 실행을 종료한다.
- 운영체제에 프로그램이 정상적으로 종료되었음을 나타내는 값 0을 반환한다.

## 4. MODE 값에 따른 실행 결과 비교

| MODE 값 | 선택되는 조건 | 출력 결과 |
|---------|--------------|-----------|
| 1 | `#if MODE == 1` | Mode 1: Debug mode |
| 2 | `#elif MODE == 2` | Mode 2: Normal mode |
| 3 | `#elif MODE == 3` | Mode 3: Power saving mode |
| 5 | `#else` | Unknown mode |

`MODE` 값을 변경한 후 다시 컴파일하면 다른 코드가 선택된다.

---

## 5. 일반 if문과 #if문의 차이점

| 구분 | if문 | #if 지시자 |
|------|------|------------|
| 처리 시점 | 프로그램 실행 중 | 컴파일 전 전처리 단계 |
| 조건 검사 | 실행 시 조건 검사 | 전처리 시 조건 검사 |
| 조건에 사용되는 값 | 변수, 상수 등 | 매크로 및 정수 상수 표현식 |
| 코드 선택 | 실행할 분기 선택 | 컴파일할 코드 영역 선택 |
| 주요 용도 | 프로그램 실행 흐름 제어 | 조건부 컴파일 |

일반 `if`문은 실행 중에 변수의 값에 따라 다른 동작을 수행할 때 사용한다.

반면 `#if` 지시자는 프로그램을 컴파일하기 전에 필요한 코드만 선택해야 할 때 사용한다.

---

## 6. 결론

`#if ~ #elif ~ #endif`는 전처리 단계에서 조건에 따라 컴파일할 소스코드를 선택하는 기능이다.

이를 사용하면 하나의 프로그램에서도 디버그 모드, 일반 모드, 절전 모드 등 다양한 설정을 쉽게 관리할 수 있다.

이번 예제에서는 `#define MODE 2`로 설정하였기 때문에 `#elif MODE == 2` 조건에 해당하는 코드만 컴파일되어 `Mode 2: Normal mode`가 출력된다.

따라서 조건부 컴파일은 프로그램의 유지보수성을 높이고, 운영체제나 하드웨어 환경에 따라 필요한 코드만 선택하는 데 유용하다.
