
# 매크로 상수를 사용한 C언어 프로그램 실습

## 1. 실습 목적

인터넷에서 매크로 상수를 사용하는 C언어 예제를 찾아 실행하고, `#define` 전처리 지시문의 역할과 소스코드의 동작 원리를 이해한다.

## 2. 매크로 상수란?

매크로 상수는 C언어에서 `#define` 전처리 지시문을 사용하여 특정 이름에 고정된 값을 지정한 것이다.

프로그램의 전처리 단계에서 매크로 이름이 지정된 값이나 식으로 치환된다.

**기본 형식**

```c
#define 매크로이름 값
```

**예시**

```c
#define WIDTH 80
#define PI 3.14159
```

- `#define`: 매크로를 정의하는 전처리 지시문
- `WIDTH`: 매크로 상수의 이름
- `80`: 매크로 상수에 대응하는 값
- 매크로 상수는 일반적으로 대문자로 작성한다.
- `#define` 문장 끝에는 세미콜론(`;`)을 붙이지 않는다.

매크로 상수는 일반 변수와 달리 별도의 자료형을 선언하지 않으며, 전처리 과정에서 이름이 치환된다.

## 3. 인터넷에서 찾은 예제

**참고 자료**

- 사이트: Microsoft Learn
- 문서명: #define directive (C/C++)
- URL: https://learn.microsoft.com/en-us/cpp/preprocessor/hash-define-directive-c-cpp

Microsoft 공식 문서에서는 다음과 같이 매크로 상수를 정의하는 예제를 제공한다.

```c
#define WIDTH 80
#define LENGTH (WIDTH + 10)
```

이 예제를 기반으로 직사각형의 가로, 세로, 넓이를 출력하는 프로그램을 작성하였다.

### 전체 소스코드

```c
#include <stdio.h>

#define WIDTH 80
#define LENGTH (WIDTH + 10)

int main(void)
{
    int area = WIDTH * LENGTH;

    printf("Width: %d\n", WIDTH);
    printf("Length: %d\n", LENGTH);
    printf("Area: %d\n", area);

    return 0;
}
```

※ 매크로 정의는 Microsoft 공식 문서를 참고하였으며, `main()` 함수와 출력 코드는 실습을 위해 구성하였다.

## 4. 소스코드 상세 설명

### ① 헤더 파일 포함

```c
#include <stdio.h>
```

- `#include`는 헤더 파일을 포함하는 전처리 지시문이다.
- `stdio.h`는 표준 입출력 관련 함수의 선언이 포함된 헤더 파일이다.
- 프로그램에서 사용하는 `printf()` 함수의 선언을 제공한다.

### ② 매크로 상수 정의

```c
#define WIDTH 80
```

- `WIDTH`라는 매크로 상수를 정의한다.
- 소스코드에서 `WIDTH`를 사용하면 전처리 과정에서 `80`으로 치환된다.
- 직사각형의 가로 길이를 의미한다.

```c
#define LENGTH (WIDTH + 10)
```

- `LENGTH`라는 매크로 상수를 정의한다.
- `WIDTH`에 10을 더한 식을 나타낸다.
- 전처리 과정에서 `WIDTH`도 치환되므로 최종적으로 `(80 + 10)`이 된다.
- 따라서 세로 길이의 계산 결과는 90이다.

### ③ main 함수

```c
int main(void)
{
```

- `main()`은 프로그램 실행이 시작되는 함수이다.
- `int`는 함수가 정수형 값을 반환한다는 의미이다.
- `void`는 함수가 전달받는 매개변수가 없다는 의미이다.

### ④ 직사각형 넓이 계산

```c
int area = WIDTH * LENGTH;
```

- `int`는 정수형 자료형이다.
- `area`는 직사각형의 넓이를 저장하는 변수이다.
- `WIDTH`와 `LENGTH`를 곱하여 넓이를 계산한다.

전처리 이후 식은 다음과 같이 변환된다.

```c
int area = 80 * (80 + 10);
```

따라서 계산 결과는 다음과 같다.

```text
80 × 90 = 7200
```

변수 `area`에는 7200이 저장된다.

### ⑤ printf 함수로 결과 출력

```c
printf("Width: %d\n", WIDTH);
```

- `printf()`는 화면에 데이터를 출력하는 함수이다.
- `%d`는 정수를 출력하는 서식 지정자이다.
- `\n`은 줄바꿈을 의미한다.
- `WIDTH`의 값인 80이 출력된다.

```c
printf("Length: %d\n", LENGTH);
```

- `LENGTH`에 해당하는 식의 계산 결과인 90을 출력한다.

```c
printf("Area: %d\n", area);
```

- `area` 변수에 저장된 7200을 출력한다.

### ⑥ 프로그램 종료

```c
return 0;
```

- `main()` 함수의 실행을 종료한다.
- 일반적으로 0을 반환하면 프로그램이 정상적으로 종료되었음을 의미한다.

GCC 컴파일러를 사용하여 코드를 컴파일하고 실행하였다.

**실행 결과**

```text

```

**결과 분석**

| 항목 | 계산 과정 | 결과 |

| 넓이(area) | 80 × 90 | 7200 |

프로그램이 정상적으로 실행되었으며, 매크로 상수가 전처리 단계에서 치환되어 계산에 사용되는 것을 확인하였다.

Visual Studio에서 소스코드를 실행한 후 출력 결과가 표시된 콘솔 화면을 캡처하여 첨부한다.

## 6. 매크로 상수의 특징과 장점

### ① 코드 가독성 향상

숫자를 직접 사용하는 대신 의미 있는 이름을 사용하면 코드의 목적을 쉽게 이해할 수 있다.

예를 들어 `80 * 90`보다 `WIDTH * LENGTH`가 어떤 값을 계산하는지 더 명확하다.

### ② 유지보수 편리

매크로를 여러 곳에서 사용하더라도 정의된 값을 변경하면 해당 매크로를 사용하는 코드에 변경 사항이 반영된다.

### ③ 전처리 단계에서 치환

매크로 상수는 컴파일 이전에 전처리기에 의해 치환된다.

일반 변수처럼 값이 저장되는 별도의 변수 객체를 생성하는 것은 아니다.

### ④ 사용 시 주의사항

매크로 상수는 자료형 검사를 직접 받는 변수가 아니므로 잘못 사용하면 예상하지 못한 결과가 발생할 수 있다.

특히 계산식으로 정의하는 경우 연산자 우선순위 문제를 방지하기 위해 괄호를 사용하는 것이 좋다.

예시:

```c
#define LENGTH (WIDTH + 10)
```

이번 실습에서는 `#define`을 사용하여 `WIDTH`와 `LENGTH` 매크로 상수를 정의하고, 이를 활용하여 직사각형의 넓이를 계산하였다.

실행 결과 가로 80, 세로 90, 넓이 7200이 정상적으로 출력되는 것을 확인하였다.
